How it behaves

  • Seasons and episodes are matched by number — running the same import twice will not create duplicates.
  • Existing episodes get their title, runtime, air date and artwork refreshed; blank descriptions and thumbnails are filled in.
  • Download links, storage servers, view counts and hand-written copy are never overwritten.
  • If nothing changed, the result is reported as a warning instead of a success — no more silent no-ops.
